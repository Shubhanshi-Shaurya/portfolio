# Personal Portfolio

A simple and responsive personal portfolio website built using **HTML, CSS, and JavaScript**. It showcases my skills, projects, education, achievements, and professional profiles.

---

## Features

*  Home section
*  About Me
*  Skills & Technologies
*  Projects
*  Education
*  Achievements
*  Contact section
*  Responsive design
*  Social & professional profile links

---

##  Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and dynamic elements

---

##  Project Structure

```text
portfolio/
├── index.html

├── images/

```

##  Getting Started

### Clone the repository

```bash
git clone https://github.com/Shubhanshi-Shaurya/portfolio
```

### Open the project

Navigate to the project folder and open `index.html` in your browser.
